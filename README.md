# Мария Белякова · визовый консалтинг

Одностраничный интерактивный макет личного сайта. Русский язык, адаптивная
вёрстка, светлая палитра с глубоким зелёным, личная подача эксперта.

## Посмотреть и поделиться

Макет уже доступен на телефоне и компьютере:
**https://sergisaev.github.io/VisaMB/**.

Для повторной настройки GitHub Pages в этом репозитории:

1. Откройте [Settings → Pages](https://github.com/Sergisaev/VisaMB/settings/pages).
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь успешной сборки Pages. Адрес сайта после включения:
   **https://sergisaev.github.io/VisaMB/**.

Наличие файлов в репозитории само по себе не означает, что Pages уже включён.
Доступность Pages для закрытого репозитория зависит от тарифа GitHub;
видимость самого репозитория без согласования менять не нужно.

Откройте `index.html` в современном браузере. Это автономный файл:
CSS, JavaScript, шрифты и изображение встроены. Сборка, установка пакетов,
интернет и сервер для просмотра не нужны. Можно переслать сам файл;
внизу страницы также есть кнопка «Скачать макет».

Для локального просмотра через HTTP:

```sh
cd /workspace/Codex
python -m http.server 8000 --bind 0.0.0.0
```

## Что работает

- Пять направлений с переключением содержимого и управлением с клавиатуры.
- Главная воронка: кнопки в шапке, первом экране, направлениях, FAQ и финальном
  блоке открывают действующего бота https://t.me/VisaMB_consult_bot.
- В финальном блоке значок Telegram крупнее соседних WhatsApp и MAX.
  На первом экране эти два мессенджера представлены меньшими кнопками.
  До добавления реальных контактов для них также показывается предпросмотр.
- Второстепенная форма «Удобнее оставить контакт?» свёрнута по умолчанию.
  Она проверяет поля, показывает текст заявки и позволяет его скопировать.
- Раскрывающиеся ответы, мобильное меню, модальные окна и скачивание HTML.
- Нет выбора города: работа с заявлениями по Москве и Санкт-Петербургу
  обозначена текстом.
- На мобильном экране увеличены текст и зоны нажатия, кнопки стран остаются
  видимыми, значки мессенджеров выровнены. Прокрутка сохраняется после закрытия
  модального окна; его кнопка закрытия доступна и на коротком экране.

## Проверить мобильную версию

Для разработки нужны Node.js, пакет `playwright` и соответствующий браузер.
Системный Chromium используется автоматически, если доступен в `/usr/bin/chromium`;
иначе нужен браузер из установки Playwright.

```sh
node tests/mobile-ux.cjs
MOBILE_TEST_ENGINE=webkit node tests/mobile-ux.cjs
```

Проверки запускают свой временный локальный сервер и закрывают его после работы.
Они охватывают 12 размеров экрана (320–1440 px), все пять направлений, зоны
нажатия, меню, расположение элементов, форму и прокрутку модальных окон.
Для проверки скачанного экземпляра можно указать путь в `MOBILE_TEST_HTML`.

## Подключить бота

В `index.html` найдите единственную константу:

```js
const TELEGRAM_BOT_URL = 'https://t.me/VisaMB_consult_bot';
```

Бот уже подключён. Все пять основных кнопок открывают этот адрес в новой
вкладке; ссылки работают и без JavaScript. Для смены бота измените константу
и адреса ссылок с атрибутом `data-telegram`. Дополнительные параметры
и сценарии бота макет не предполагает.

Адреса второстепенных каналов задаются рядом, в `MESSENGER_URLS`:

```js
const MESSENGER_URLS = {whatsapp:'', max:''};
```

Вставьте согласованные публичные ссылки. Пустое значение сохраняет
демонстрационный режим соответствующей кнопки.

## Границы прототипа

Демонстрационная веб-форма не отправляет заявки. Данные формы не записываются в хранилище сайта,
аналитика и внешние загрузки отсутствуют. Скачиваемый экземпляр HTML не содержит
заполненных полей и текста заявки. Серверная отправка и реальные второстепенные
контакты не подключены; перед запуском нужны согласованные реквизиты,
формулировки услуг и документы об обработке персональных данных.

Фиктивные цены, отзывы, стаж и статистика одобрений не добавлялись. По США и Канаде
представлена платная консультация; по Шенгену, Кипру и Японии — онлайн-помощь
с подготовкой. Решение о выдаче визы остаётся за консульством.
